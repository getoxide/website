# Oxide website

The public website of Oxide, the desktop app for agentic coding. Product terms (Project, Thread, Turn, Provider…) belong to the Oxide repo's glossary; these are the site's own.

## Language

**Canonical definition**:
The one sentence that says what Oxide is, owned by the Oxide README and never reworded.
_Avoid_: tagline, description

**Snapshot**:
The copy of Oxide's product facts the site renders, taken at one Oxide release tag.
_Avoid_: cache, content dump

**Release state**:
Whether Oxide has a stable release, only a test pre-release, or none; it decides every download CTA.
_Avoid_: launch status

**Budget class**:
The performance tier a page belongs to: showcase or reading.
_Avoid_: page type

**Capture**:
A still or a loop recorded from the real Oxide UI.
_Avoid_: screenshot, mock-up, render

**Locked string**:
Copy rendered verbatim from the Copy deck.

**Outline**:
Copy whose headings and key sentences the Copy deck fixes, with the running text written by the build.

**Derived**:
Copy rendered from the Snapshot, never written on the site.
